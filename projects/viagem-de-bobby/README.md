# A Viagem de Bobby

Shoot-em-up espacial em TypeScript + Canvas 2D. Continuação direta de A Fuga de Bobby.

## Arquivos esperados

- `video/main.mp4` — vídeo de gameplay (opcional, vira o item principal se existir)
- `capa/cover.jpg` — imagem de capa (usada se não tiver vídeo)
- `screenshots/01.jpg`, `02.jpg`, `03.jpg` — prints da galeria

## Como editar

1. Coloca os arquivos nas pastas
2. Abre `info.json` e ajusta os nomes se forem diferentes
3. Muda `media.demo` para `false` pra ativar carregamento real
4. Se algum arquivo não existir, o modal cai no placeholder colorido automaticamente
