# A Fuga de Bobby

Plataforma retrô em TypeScript + Canvas 2D.

## Estrutura

```
fuga-de-bobby/
├── capa/
│   ├── CapaFuga.png           ← capa oficial
│   └── CapaFuga-2.png         ← alternativa
├── screenshots/
│   ├── print1.png
│   ├── print2.png
│   └── print3.png
├── info.json
└── README.md
```

## Vídeo

Link do Google Drive no campo `media.drive` do `info.json`.

## Como editar

1. **Capa:** troca em `capa/` e atualiza `media.capa`
2. **Prints:** troca em `screenshots/` e atualiza `media.prints`
3. **Vídeo:** atualiza `media.drive`
