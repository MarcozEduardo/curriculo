# Estilos Modulares - Currículo & Chat Bobby

Esta pasta contém a divisão de CSS para manter as folhas de estilo leves, fáceis de dar manutenção e organizadas por responsabilidades (abaixo de 200 linhas por arquivo).

## 🗂️ Arquivos e Funções

- `layout.css` -> Estrutura global, sistema de grid, cores, folhas e utilitários de reset.
- `header.css` -> O topo estilo App (tipo WhatsApp/tablet), foto com botão de câmera (estático) e barra de status.
- `projects.css` -> Layout de cards para os projetos, com cores exclusivas para cada tipo de status (Jogável, Em Refinamento, Em Testes, Concluído).
- `experience.css` -> Estilização da linha do tempo, cards de histórico profissional e formação.
- `chat.css` -> Interface do Chatbot Bobby (modal, balões de diálogo, indicador de digitação e badge de fontes RAG).
- `mobile.css` -> Abas inferiores fixas, sticky mini-header e regras de responsividade para celular e tablet.
- `print-a4.css` -> Regras exclusivas para impressão e exportação via html2pdf (A4 limpo, sem chat, sem botões de tela, com links clicáveis).
