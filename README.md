# 🎯 Currículo Inteligente — Marcos Eduardo

Currículo conversacional com **RAG local embarcado** em JavaScript puro, sem IA generativa e sem API paga.

## 🧠 O que é

Um currículo interativo que permite ao recrutador conversar diretamente com a base de conhecimento do Marcos. O motor é um RAG arquitetado por órbitas (temas), satélites (assuntos) e facetas (o que se pergunta).

## 🚀 Stack

- **Engine RAG**: JavaScript puro (sem framework)
- **Arquitetura**: Órbitas + Facetas + Deepening Trees
- **Deploy**: Vercel
- **Fuzzy Matching**: Similaridade de tokens com tolerância a erro de digitação
- **Memória de Sessão**: Contexto pegajoso com anti-repetição

## 📂 Estrutura

```
curriculo/
├── index.html          → página principal
├── chat-rag/           → motor RAG (órbitas, facets, responses)
├── ProjetoNovoRag/     → nova arquitetura de regras gramaticais
├── data/               → JSON do currículo
├── sections/           → seções modulares
├── css/                → estilos
├── js/                 → scripts de UI
├── projects/           → projetos do portfólio
└── Docs/               → documentação técnica
```
